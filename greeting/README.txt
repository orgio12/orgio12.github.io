NOMIA · NINETEEN
Birthday page + three-level landscape adventure

OPEN
Unzip everything, then open index.html in a modern browser.
Keep the assets, vendor, JavaScript and CSS alongside the HTML files.
No build step, login, API key or server is needed.
On phones, play game.html in landscape with both thumbs.
Use the theme button to switch between light pink and dark tech.
Theme and sound preferences are saved on this browser.

EDITING
The letter is between EDIT YOUR LETTER BELOW and END OF LETTER in index.html.
Your uploaded letter and reason texts have been retained.
Change reason notes in content.js. Source uses tabs and readable line breaks.
Keep photo dimensions square; the frames show the complete image.

NOMIAPC
Only the important condition inside if (...) needs to be entered.
Symbol buttons and optional dropdowns reduce typing on a phone.
The supplied loop counts groups of W characters in a string.
The local interpreter evaluates behavior, not an exact answer string.
Equivalent supported expressions are accepted. AC and WA have cute reactions.
This is a focused C++-style exercise, not a complete C++ compiler.
Unsupported syntax and execution limits have separate messages.
No submitted code is sent to an external service.

MINI-GAMES
Memory matching, catching 19 stars, and Little star echoes (three rounds
of repeating an increasingly long pattern).

ADVENTURE
Arrows or A/D: move. Space, W or Up: jump; press again for double jump.
Z or J: fire. Hold FIRE to keep shooting; it aims toward nearby enemies.
Shift or X: dash shield. P or Escape: pause. E: enter the secret room nearby.
Touch controls support simultaneous movement, jumping and firing.
Clear every enemy, collect 19 stars, then reach the gift to win a world.
Three worlds increase enemy health and firing frequency gradually.
Five hearts, checkpoints, unlimited retries and no forced time limit.
Progress is saved locally. Retry preserves collected stars and enemy damage.
Look behind the big mushroom for a secret room and a healing gift.

HOSTING
Upload this folder's contents to the root of a static web host.
Choose your own site name or custom domain. No particular hostname is needed.
A Git push publishes only if hosting is configured for that repository.
The site has no platform branding, remote fonts, analytics or external APIs.

PRINTABLE QR
After hosting, open qr.html and paste the final HTTPS website address.
Generate the QR, scan it on a phone, then print or save the PNG.
Use your published website URL, not the ZIP download or a local file path.
Keep the address unchanged after printing. QR generation runs locally.

VALIDATION
Phone-sized layout, theme switching, AC submission, candle and envelope
interactions inspected in a browser. Game logic checked for multi-hit combat,
level goals, double jump, saved progress, secret reward and death/retry.
Equivalent code solutions and incorrect answers checked separately.
A final real-device two-thumb playthrough is recommended before gifting.
