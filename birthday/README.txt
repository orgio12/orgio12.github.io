NOMYA · NINETEEN
Birthday page + three-level landscape adventure — draft

OPEN
Unzip the whole folder, then open index.html in a modern browser.
Keep assets, vendor, JavaScript and CSS beside the HTML files.
The adventure is game.html. On phones, rotate to landscape.
No build step, login, API key or server is needed for this draft.

EDIT
index.html: birthday greeting, photo captions, problem statement and letter.
The letter starts below the comment EDIT YOUR LETTER BELOW.
page.js: the 19 reasons and small game messages.
style.css: main page colors, spacing and responsive layout.
game.js / game.css: adventure levels and controls.
assets: four square photographs and the original saved character image.

CODE CHALLENGE
She completes the whole solve() algorithm and return statement.
The local interpreter supports the syntax listed under the editor. It is
not a full C++ compiler. Correct supported algorithms are run against
1,033 tests, including every A/W string up to length nine and long cases.
Verdicts: AC, WA, syntax error, runtime error and execution limit.
No hints are shown. Unsupported valid C++ needs a full compiler integration
in a future version; it is not silently accepted or treated as real C++.

ADVENTURE
Left/right arrows or A/D: move.
Space, W or Up: jump; press twice for double jump.
Shift or X: dash with a brief shield; recharges after two seconds.
P or Escape: pause. Touch controls support simultaneous left/right and jump.
Collect all 19 stars per world, then reach the gift at the far right.
Three worlds, 57 stars, patrolling clouds, three hearts, unlimited retries.
Checkpoints shorten the return after losing a heart. Losing all hearts
restarts the current level. There is no forced time limit.

HOSTING
Upload the contents of this folder to the root of any static web host.
Use a site name or custom domain of your choice. The website does not
require any particular hostname and contains no platform branding.
A Git push only publishes it if hosting is configured for that repository.
There are no remote fonts, analytics, CDNs or external API requests.

PRINTABLE QR
After hosting, open qr.html and paste the final https website address.
Generate QR, scan it on a phone, then print the card or save the PNG.
Use the published website URL, not the ZIP download or a local file path.
Keep that URL unchanged after printing. The QR generator runs locally.
